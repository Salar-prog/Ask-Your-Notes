UnoRouter config

The key stays in this browser and is sent only to the local proxy. Run UPSTREAM=https://api.unorouter.com/v1 node serve.mjs, open http://localhost:8080, then ask. No key? The local reader answers from the notes.

Free models allow about one request per minute. The local reader works with no key, so the page never depends on the API to answer. Grounding checks figures only; names and dates are the model's job.
