UnoRouter config

The key stays in this browser and is sent only to the local proxy. Run UPSTREAM=https://api.unorouter.com/v1 node serve.mjs, open http://localhost:8080, then ask. No key? The local reader answers from the notes.

Free models allow about one request per minute. The local reader works with no key, so the page never depends on the API to answer. A sentence must match half the question to count as evidence, and a two-sided note is answered with both sides. Figures and dates must come from the notes or the live fact; a name that is not in either is listed under the answer.
